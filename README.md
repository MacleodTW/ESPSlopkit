# ESPSlopkit
ESP32 Slopkit is built from VS Code with PlatformIO.
It tested on ESP32-S3FN8 dongle

![image](https://github.com/MacleodTW/ESPSlopkit/blob/main/ESP32%20S3%20Dongle.png)


Usage:
1. Download release ESPSlopkit_xxx.zip
2. Flash ESP32-S3 dongle with the tool inside zip
3. Plug ESP32-S3 dongle to recycle power
4. Phone or PC WiFi connect to "PS_WiFi" SSID, password is "password"
5. Use browser to https://10.1.1.1 (Contiue insecure)
6. Set STA WiFi SSID and STA WiFi password then click "Save"
7. Reload browser get STA IP
8. PS5 set DNS server to STA IP
9. PS5 Settings -> Guide & Tips, Health and Safety, and Other information -> User's Guide -> 
   If it shows security xxx click "Yes"
